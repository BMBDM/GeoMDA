# Data source

The data in this directory were obtained from the supplementary materials of the SCAD study and are used for research purposes.

Zheng, Zetian, Junyi Chen, Xingjian Chen, Lei Huang, Weidun Xie, Qiuzhen Lin, Xiangtao Li, and Ka‐Chun Wong. "Enabling single‐cell drug response annotations from bulk RNA‐Seq using SCAD." Advanced Science 10, no. 11 (2023): 2204113.
